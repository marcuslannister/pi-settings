# pi-settings

Tracked config for the `pi` agent (`~/.pi`). Versioned: `agent/settings.json`,
`agent/mcp.json`, `agent/pi-statusline.json`, and `agent/extensions/`.
`auth.json`, `models-store.json`, `mcp-cache.json`, and session logs are ignored.

## Agent skills

### Issue tracker

GitHub Issues on `marcuslannister/pi-settings`, via the `gh` CLI. See `docs/agents/issue-tracker.md`.

### Triage labels

Canonical five, label string = role name. See `docs/agents/triage-labels.md`.

### Domain docs

Single-context — `CONTEXT.md` + `docs/adr/` at the repo root. See `docs/agents/domain.md`.
